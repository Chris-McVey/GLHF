# Canonical set bundles

Pre-curated platform libraries shipped with the app. Generated by
`Tooling/canonical-sets/curate.py` — do not edit by hand.

## `nes.json`

| Field | Value (2026-05-18 build) |
|-------|--------------------------|
| Bundle ID | `nes-20260518` |
| Schema | 3 |
| Games | 826 (741 licensed, 85 unlicensed) |
| RAWG IDs | 752 (91%) |
| Region | Western (US + PAL NES releases) |

**Regenerate:** from repo root,

```bash
cd Tooling/canonical-sets
uv run curate.py --platform nes
cp output/nes.json ../../GLHF/Resources/CanonicalSets/nes.json
```

Editorial decisions live in `Tooling/canonical-sets/overrides/nes.toml`.
The review report is `Tooling/canonical-sets/output/review/nes-review.md`
(gitignored).

**No-Intro:** placing `data/no-intro/nes.dat` (from DAT-o-MATIC) before
curating upgrades matches from 2/3 → 3/3 source tier. Optional for v1.

**Phase B (app):** load this file at first launch; `rawgID` drives cover
art via `RAWGService`. Entries with `rawgID: null` need runtime search fallback.
